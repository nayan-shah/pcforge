Technical Review & Architecture Specification

PCForge — Project Review

Repository: nayan-shah/pcforge  |  Stack: React 18, TypeScript, Node.js, Express, MongoDB, Playwright  |  Date: September 2026

Executive Summary: PCForge is a production-oriented monorepo powering an Indian PC hardware price comparison, catalog, and custom PC builder platform. It integrates live web scrapers (MDComputers, Vedant, PrimeABGB, PCStudio), a dynamic compatibility/specification parser, power (TDP) calculations, and authenticated build snapshots.

2. Key Features

  • Live Price Scraping & Aggregation: Concurrent non-blocking retailer queries across Indian stores with Jaccard token similarity deduplication.
  • Auto-Specification Extraction: Regex parser automatically extracts socket (AM5, LGA1700), DDR standard, and TDP power draw from component names.
  • Interactive PC Builder: 8-slot builder with live wattage/cost aggregation and snapshot storage.
  • Role-Based Access Control: JWT authentication with database-enforced admin verification for component management.
  • AI Hardware Consultant: Preset archetype matching with hardware bottleneck reasoning.
